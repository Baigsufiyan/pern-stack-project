# PERN Stack Project

A full-stack web application built with PostgreSQL, Express.js, React, and Node.js.

## Features

- CRUD operations with PostgreSQL
- RESTful API using Express.js
- React frontend with routing
- Zustand for state management
- Tailwind CSS with DaisyUI for styling
- PostgreSQL hosted on Neon
- Deployed on Vercel

## Tech Stack

- **Frontend:** React, React Router, Zustand, Tailwind CSS, DaisyUI
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL (Neon)
- **Deployment:** Vercel (frontend), Neon.tech (database)

## Getting Started

### Prerequisites

- Node.js (v18 or higher)
- PostgreSQL account (e.g. Neon.tech)
- Git
